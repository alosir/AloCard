# AloCard 账期日期引擎

规则来源：`CONTEXT.md` 与 `adr/0001`–`0008`（免息期为今日视角、账单日 1–28 不做月末兜底、还款日 = 账单日 + N、到期 ≠ 逾期）。

算法：按本地日历日运算。日期用 `new Date(y, m-1, d)` 构造，天数差用 `Date.UTC` 整数差而非毫秒除法，不受夏令时影响；账单日按「加一月并 clamp 到目标月天数」推进。`refDate` 接受 Date 或 `'YYYY-MM-DD'`。

两处读法：

1. 规则 1/2 为「≥D 的最小账单日（等于也算）」与「≤D 的最大账单日」，当天重合，当天即返回当天。清单用例 4/5 期望「当天推进到次月、闰年 2 月取 29 日」，与规则 1/2/3、用例 2 矛盾，按规则实现；`billingDay ≤ 28` 时 `2028-02-29` 不会是账单日，闰年体现在周期长度。
2. 待完善（规则 8）：缺 `billingDay` 或 `dueOffsetDays` 时，免息期与距还款日返回 `null`（统一不可用标记）。
